# AI Usage

## Tools Used

- ChatGPT
- GitHub Copilot

AI-assisted development tools were used during this project to support implementation, debugging, test authoring, UI refinement, and documentation tasks.

## AI Usage

AI was used for:

- implementation assistance
- debugging and troubleshooting
- test generation and validation support
- frontend UI refinement
- documentation drafting

All generated output was reviewed, adapted, and validated by the developer. Final decisions about architecture, integration details, verification, and acceptance were made by the developer.

## Human Responsibility

The developer remained responsible for:

- requirements interpretation
- architecture decisions
- implementation direction
- reviewing generated code
- integrating generated code
- debugging and issue analysis
- validating API contracts
- running the relevant test suites
- browser and runtime verification
- final acceptance of the work

## Verification

The following verification steps were performed as part of review and validation:

- frontend lint
- TypeScript type checking
- production build validation
- backend pytest execution
- API smoke testing against the live backend
- browser/runtime validation
- responsive viewport checks

## Limitations

AI-generated suggestions were treated as supporting input rather than as a substitute for developer review. Final implementation quality, correctness, and acceptance depend on human verification, implementation judgment, and project-specific validation.
